What the code shows

  • State is spread across dictionary keys, callbacks, sets, timestamps, files, and process handles.
  • The main safety rule is delivery before progress. Inferred turn endings and daily attempt markers follow different rules.
  • This inventory describes existing behavior. It makes no application changes and proposes no framework migration.
  • Scope limit: external database jobs and live service behavior can add transitions beyond this checkout. See the coverage section.

What counts here

A state machine remembers prior events and uses that memory to change how it handles the next event.

The state names below are descriptive unless the source already names them. A row can describe an extended state machine with counters, timestamps, or sets.

Ordinary arithmetic, pure classifiers, raw counters, and generic runtime internals are excluded. Simple caches appear only where their state affects retries, attribution, or resource use.
